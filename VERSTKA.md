# Оливия — вёрстка сайта и мини-приложения MAX

Чистый HTML/CSS/JS без сборки. Открывается с любого хостинга (nginx, GitHub Pages, Timeweb, рег.ру).

```
site/        сайт-лендинг
  index.html       главная
  privacy.html     политика ПД (шаблон, заполнить реквизиты)
  css/style.css    все стили (цвета — в :root)
  js/config.js     ← настройки: API, ссылки MAX/Telegram/VK, Яндекс.Метрика
  js/main.js       меню, анимации, маска телефона, форма, лайтбокс
  img/             фото (webp), логотипы, иконки, og.jpg
miniapp/     мини-приложение MAX
  index.html       экраны: Главная, Каталог, Работы, Акции, Запись, Готово
  css/app.css
  js/config.js     ← адрес API
  js/app.js        навигация, MAX Bridge, запись на замер
```

## Что заполнить перед запуском
Всё, что в квадратных скобках `[___]`:
- цены «от» для стилей (site/index.html, miniapp/index.html);
- гарантия, материалы, % скидки в акции, режим работы;
- отзывы (блок «Что говорят клиенты»);
- реквизиты в privacy.html;
- `site/js/config.js`: ссылки на MAX-бота, Telegram, группу VK, номер Метрики;
- домен в `<link rel="canonical">` и `og:image` (абсолютный URL).

Фото шкафов-купе, гардеробных, прихожих и стилей «Классика/Лофт» — временные. Замените файлы в `img/` с теми же именами.

## Заявки (API)
Обе формы отправляют `POST` JSON на `apiUrl` из config.js. Пока `apiUrl` пустой — форма показывает успех и пишет заявку в консоль.

```json
{
  "source": "site | max | miniapp-web",
  "name": "Анна",
  "phone": "+79141234567",
  "service": "Кухня | Шкаф-купе | Гардеробная | Прихожая | Другое",
  "date": "2026-10-30",          // только мини-приложение
  "time": "14:00",               // только мини-приложение
  "comment": "...",
  "page": "https://...",         // только сайт
  "max_init_data": "...",        // строка WebApp.initData — проверять подпись на сервере
  "max_contact": {"phone": "...", "authDate": 0, "hash": "..."}  // если номер взят кнопкой «Из MAX»
}
```
Ответ 2xx = успех. Бэкенд должен присылать заявку Оле в Telegram/MAX.

## MAX
- Подключён MAX Bridge `https://st.max.ru/js/max-web-app.js` (объект `window.WebApp`).
- Внутри MAX: приветствие по имени, имя подставляется в форму, системная кнопка «Назад», кнопка «Из MAX» для номера телефона, виброотклик.
- Вне MAX работает как обычный мобильный сайт.
- Для публикации: создать бота на платформе MAX для партнёров, указать URL папки `miniapp/` (только HTTPS).
